# 자리 — Releases

[자리](https://jari-home.goldhandtauri.workers.dev) 의 **설치 파일만** 두는 자리입니다.
앱 소스는 비공개 저장소에 있습니다.

> 🚨 **이 저장소는 공개입니다.** 여기 올리는 것은 전부 밖에서 보입니다 —
> 서명 열쇠 · 토큰 · 서버 설정 같은 것을 실수로 함께 올리지 않습니다.

## 받는 곳

- 사람이 받는 곳: **https://jari-home.goldhandtauri.workers.dev/download**
- 파일 자체: [Releases](https://github.com/onu-soft/jari-releases/releases)

## 🚨 프로그램이 둘, 기계가 둘 — 그래서 판마다 파일이 **넷**입니다

세로는 **어느 기계에 까나**, 가로는 **그 기계가 무엇이냐**입니다.
받는 사람은 **가로로 고르고 세로로는 안 고릅니다** — 둘 다 필요합니다.

| | 무엇을 하나 | 맥 | 윈도우 |
|---|---|---|---|
| **부모 앱** (여는 쪽) | 짝짓고 · 잠그고 · 엽니다. 진도를 봅니다 | `Jari-Parent-mac-<판>.dmg` | `Jari-Parent-win-<판>.exe` |
| **아이 기기 앱** (잠기는 쪽) | 잠금을 실제로 집행합니다 | `Jari-Child-mac-<판>.zip` | `Jari-Child-win-<판>.zip` |

⚠️ 부모 앱만 받아 가면 아무것도 안 잠기고, 아이 앱만 깔면 아무도 못 엽니다.

## 🚨 파일 이름 약속 — 제품 낱말과 OS 낱말이 **둘 다** 있어야 합니다

홈페이지의 다운로드 단추는 **최신 릴리스의 자산 목록을 읽어** 붙습니다
(`jari_home/src/data/downloads.ts`). 상수로 켜고 끄지 않습니다 — 켜는 걸 잊으면 준비된
파일을 아무도 못 받고, 미리 켜 두면 없는 파일을 가리켜 404 가 됩니다.

고를 때 **확장자 · 제품 낱말 · OS 낱말 셋을 다** 봅니다.

| 칸 | 이 확장자만 후보 | 제품 낱말 | OS 낱말 |
|---|---|---|---|
| 맥 **부모 앱** | `.dmg` | `parent` · `부모` | `mac`·`macos`·`osx`·`darwin`·`apple` |
| 윈도우 **부모 앱** | `.exe` · `.msi` | `parent` · `부모` | `win`·`windows`·`x64`·`x86`·`msvc` |
| 맥 **아이 기기 앱** | `.zip` | `child` · `아이` · `guard` | `mac`·`macos`·`osx`·`darwin`·`apple` |
| 윈도우 **아이 기기 앱** | `.zip` | `child` · `아이` · `guard` | `win`·`windows`·`x64`·`x86`·`msvc` |

- 판 번호를 붙여도 됩니다. 낱말과 확장자로 고르니까요
- 🚨 **OS 낱말을 빼면 안 됩니다.** 아이 앱은 맥·윈도우가 **둘 다 `.zip`** 이라, OS 표시가
  없으면 어느 쪽인지 가릴 길이 없습니다. 그때 고르는 것은 GitHub 이 자산을 돌려주는
  **순서**이고 — 아무도 정할 수 없는 값입니다. 윈도우 부모에게 맥 파일이 내려갑니다
- ⚠️ **낱말 단위로 봅니다. 부분 문자열이 아닙니다.** `darwin` 안에 `win` 이 들어 있어서,
  부분 문자열로 찾으면 맥 자산이 전부 윈도우 것으로 걸립니다
- ⚠️ 한 칸의 후보가 둘 이상이면 **아무것도 고르지 않습니다.** 잘못 고른 파일을 내려 주는
  것보다 "못 찾았다" 가 낫습니다 — 그쪽은 사람이 이 페이지로 와서 풀 수 있습니다
- 🚨 **곁들여 올리지 마세요.** 맨 `jari-guard.exe` 나 쓰지도 않는 `.msi` 를 함께 올리면
  단추에는 안 걸리지만, 이 페이지를 직접 본 사람이 그것을 받아 갑니다 — 그러면 아래
  "한 벌" 사고가 그대로 납니다

## 🚨 아이 기기 앱은 두 실행 파일이 한 벌입니다

잠금을 집행하는 쪽(`jari-guard`)과 아이에게 보이는 화면(`jari`)이 **함께 있어야** 돕니다.
하나만 올리면 받은 사람이 화면 없이 서비스만 갖게 되고, 증상은
**"준비 중이에요 에서 안 바뀐다"** 로만 나타납니다 — 제일 찾기 어려운 모양입니다.

⚠️ 그런데 **까는 자리가 판마다 다릅니다.** 그래서 설치본이 아니라 zip 으로 갑니다.

| | 윈도우 | 맥 |
|---|---|---|
| 잠금 화면 | `jari.exe` — guard 와 **같은 폴더** | `jari.app` — **`/Applications`** (guard 가 그 자리만 봅니다) |
| 지키는 쪽 | `jari-guard.exe` — 서비스 | `jari-guard` — LaunchDaemon |

압축 안에 `설치.txt` 로 순서를 함께 넣습니다. 🚨 그 순서를 건너뛰면 잠기는데 화면이 안 뜹니다.

## 올리는 법

🚨 **손으로 올리지 마세요.** 앱 저장소의 스크립트가 이름·순서·공개 시점을 다 지킵니다.

```
맥       ./scripts/release-mac.sh          맥 자산 둘 → **드래프트**
윈도우   pwsh ./scripts/release-windows.ps1  윈도우 자산 둘 → 넷 확인 → **공개**
```

### 왜 드래프트를 거치나

홈페이지가 읽는 `releases/latest` API 는 **드래프트를 건너뜁니다.** 그것을 이용합니다.

자산 넷은 두 기계에서 나옵니다. 맥이 먼저 공개해 버리면 홈페이지는 그 순간부터 맥 단추
둘만 붙이고 윈도우 두 칸은 "아직 올라오지 않았어요" 로 남습니다. 받으러 온 사람은 그것을
"윈도우는 아직 안 나왔구나" 로 읽고 돌아갑니다 — 실제로는 몇 분 뒤에 올라오는데도.
그래서 **넷이 다 찬 뒤에 한 번에** 보이게 합니다.

올린 뒤 **홈페이지를 다시 배포할 필요가 없습니다.** 다음에 페이지를 여는 사람부터
단추가 붙습니다. 확인:

```sh
curl -s https://api.github.com/repos/onu-soft/jari-releases/releases/latest | grep '"name"'
```

기대: 이름 넷. 아무것도 안 나오면 아직 **드래프트**입니다.

## ⚠️ 아직 안 된 것 — 정직하게

- **코드사인·공증을 안 했습니다.**
  - 맥 `.dmg`: 첫 실행에서 Gatekeeper 가 막습니다 — **우클릭 → 열기**로 한 번 엽니다
  - 맥 `.zip`(아이 앱): 압축으로 온 것은 우클릭으로도 안 열릴 때가 있습니다 —
    `xattr -dr com.apple.quarantine jari.app jari-guard`. 압축 안 `설치.txt` 의 0번입니다
  - 윈도우: SmartScreen 이 경고합니다 — **추가 정보 → 실행**
- **맥 빌드는 애플 실리콘 전용입니다**(`aarch64`). 인텔 맥에서는 안 돕니다
- **자동 업데이트가 없습니다.** `latest.json` 을 두지 않습니다 —
  새 판이 나오면 사람이 다시 받아야 합니다
- **자동 시작 등록이 아직입니다**(윈도우 서비스 · 맥 LaunchDaemon). 아이 컴퓨터에서
  한 번은 손이 갑니다
