# 자리 — Releases

[자리](https://jari-home.goldhandtauri.workers.dev) 의 **설치 파일만** 두는 자리입니다.
앱 소스는 비공개 저장소에 있습니다.

> 🚨 **이 저장소는 공개입니다.** 여기 올리는 것은 전부 밖에서 보입니다 —
> 서명 열쇠 · 토큰 · 서버 설정 같은 것을 실수로 함께 올리지 않습니다.

## 받는 곳

- 사람이 받는 곳: **https://jari-home.goldhandtauri.workers.dev/download**
- 파일 자체: [Releases](https://github.com/onu-soft/jari-releases/releases)

## 🚨 자리는 프로그램이 둘입니다

고르는 것이 아니라 **둘 다** 필요합니다. 가는 기계가 다릅니다.

| | 어디에 | 무엇을 하나 |
|---|---|---|
| **부모 앱** | 부모가 쓰는 맥 | 짝짓고 · 잠그고 · 엽니다. 진도를 봅니다 |
| **아이 기기 앱** | 아이가 쓰는 윈도우 컴퓨터 | 잠금을 실제로 집행합니다 |

## 🚨 파일 이름 약속

홈페이지의 다운로드 단추는 **최신 릴리스의 자산 목록을 읽어** 붙습니다
(`jari_home/src/data/downloads.ts`). 상수로 켜고 끄지 않습니다 — 켜는 걸 잊으면 준비된
파일을 아무도 못 받고, 미리 켜 두면 없는 파일을 가리켜 404 가 됩니다.

| 무엇 | 확장자 | 이름에 넣을 힌트 | 예 |
|---|---|---|---|
| 맥용 **부모 앱** | `.dmg` | `parent` 또는 `부모` | `Jari-Parent-0.1.0.dmg` |
| 윈도우용 **아이 기기 앱** | `.exe` · `.msi` · `.zip` | `child` · `아이` · `guard` | `Jari-Child-Setup-0.1.0.exe` |

- 판 번호를 붙여도 됩니다. 힌트와 확장자로 고르니까요
- 힌트가 없어도 그 확장자 후보가 **하나뿐이면** 그것을 씁니다
- ⚠️ 후보가 둘 이상인데 힌트가 없으면 **아무것도 고르지 않습니다.** 잘못 고른 파일을
  내려 주는 것보다 "못 찾았다" 가 낫습니다

## 🚨 아이 기기 앱은 두 실행 파일이 한 벌입니다

`jari-guard.exe`(잠금을 집행하는 서비스)와 `jari.exe`(아이가 보는 화면)가 **같은 폴더**에
있어야 돕니다. 하나만 올리면 받은 사람이 화면 없이 서비스만 갖게 되고, 증상은
"준비 중이에요 에서 안 바뀐다" 로만 나타납니다.

⚠️ 그래서 **한 파일로 묶어** 올립니다(설치본 하나 또는 zip 하나).

## 올리는 법

```sh
gh release create v0.1.0 \
  ./Jari-Parent-0.1.0.dmg \
  ./Jari-Child-Setup-0.1.0.exe \
  --repo onu-soft/jari-releases \
  --title "v0.1.0" --notes "..."
```

올린 뒤 **홈페이지를 다시 배포할 필요가 없습니다.** 다음에 페이지를 여는 사람부터
단추가 붙습니다. 확인:

```sh
curl -s https://api.github.com/repos/onu-soft/jari-releases/releases/latest | grep '"name"'
```

## ⚠️ 아직 안 된 것 — 정직하게

- **코드사인·공증을 안 했습니다.** 맥은 첫 실행에서 Gatekeeper 가 막습니다
  (**우클릭 → 열기**로 한 번 열어야 합니다). 윈도우는 SmartScreen 이 경고를 냅니다
- **자동 업데이트가 없습니다.** hoist 와 달리 `latest.json` 을 두지 않습니다 —
  새 판이 나오면 사람이 다시 받아야 합니다
- **자동 시작 등록이 아직입니다**(윈도우 서비스 · 맥 LaunchDaemon). 아이 컴퓨터에서
  한 번은 손이 갑니다
